# macOS
- Input needs the Accessibility permission and screenshots the Screen Recording permission for the app; if reads are empty or screenshots black, say which permission is missing.
- The menu bar belongs to the frontmost app: `bring_to_front` first, then use its menus.
- Shortcuts use cmd, not ctrl.
